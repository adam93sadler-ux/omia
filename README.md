# Omia Player

Public website for the Omia Player Android app, served via GitHub Pages from `main`:

- `index.html` — product overview, advert, four media players, personalisation preview and pricing
- `faq.html` — frequently asked questions
- `privacy.html` — privacy policy (linked from Google Play)
- `contact.html` — support and bug reporting

This repository holds only the public web pages and store-safe marketing assets. The Android app itself is not published here.
